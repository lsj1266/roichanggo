# 로이창고 (Roi Changgo)

중국·일본 구매대행과 국내 위탁 상품을 모아 정리하고, 스마트스토어 업로드용으로 가공하는 **단일 HTML 앱**과, 타오바오·티몰·1688·라쿠텐·퍼센티·온채널·오너클랜·도매매 상품을 담아 오고 **천조직구 배송대행 신청서까지 채워 주는 크롬 확장 프로그램**입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `로이창고.html` | 로이창고 웹앱 **v2.4**. 브라우저에서 열어 쓰고, 입력한 내용은 그 브라우저(localStorage)에 자동 저장됩니다. 화면 위 탭으로 **🛒 상품 작업 · 📦 천조직구 신청서 · 🏠 국내 위탁 · 🧾 세무 장부**를 오갑니다. |
| `로이창고_수집기/` | 크롬 확장 프로그램 **v2.2.1**. 상품 상세·검색 목록에서 상품명·가격·옵션·썸네일·상세사진을 한 번에 담고, 퍼센티 「신규 상품 등록」 목록은 페이지 범위·전체를 자동으로 순회해 500건씩 분할 JSON으로 저장합니다(**상품마다 원문 타오바오·1688·라쿠텐 주소 포함**). 온채널·오너클랜·도매매 상품을 담고, 천조직구 배송대행 신청서를 채워 줍니다(접수·결제는 하지 않음). |
| `로이창고_업데이트.bat` | 윈도우 원클릭 업데이터. 더블클릭 한 번으로 최신판을 받고, 바탕화면 아이콘을 만들고, 앱을 바로 엽니다. **구글 크롬이 설치되어 있으면 크롬으로 열고**, 크롬이 없을 때만 윈도우 기본 브라우저(엣지 등)로 엽니다. (Git 설치 불필요) |
| `로이창고.ico` | 바탕화면 바로가기 전용 아이콘(16·24·32·48·64·128·256px). **초록 배지에 주황 테이프를 두른 택배 상자** 그림이라 크롬 아이콘과 헷갈리지 않습니다. 업데이터가 자동으로 받아 바로가기에 지정합니다. |

## 처음 설치 (윈도우)

1. 이 저장소에서 `로이창고_업데이트.bat` 을 내려받아 **더블클릭**합니다.
   → `내 PC > 다운로드 > 로이창고` 폴더에 최신 파일이 받아지고, **바탕화면에 `로이창고` 아이콘**이 생기며, 앱이 바로 열립니다.
   (처음 실행할 때 *Windows의 PC 보호* 창이 뜨면 **[추가 정보] → [실행]** 을 누르면 됩니다. 내려받은 .bat 파일이라 한 번만 묻습니다.)
2. 다음부터는 바탕화면의 **`로이창고` 아이콘**을 더블클릭하면 앱이 바로 열립니다. (크롬이 설치되어 있으면 크롬으로 열립니다. 크롬 북마크에 두고 쓰셔도 됩니다)
3. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **[개발자 모드]** 켜기 → **[압축해제된 확장 프로그램을 로드합니다]** → `다운로드\로이창고\로이창고_수집기` 폴더 선택

## 업데이트

`로이창고_업데이트.bat` 더블클릭 → 끝나면 `chrome://extensions` 에서 **새로고침(F5) 한 번**.

> 업데이트가 끝나면 바탕화면의 `로이창고` 아이콘을 새로 만들어 주고, 앱이 자동으로 열립니다. 바로가기 아이콘은 **로이창고 전용 아이콘(`다운로드\로이창고\로이창고.ico`)** 으로 바뀌어 크롬 아이콘과 구분됩니다(그 파일이 없을 때만 크롬 아이콘으로 대신합니다). 크롬이 설치되어 있으면 아이콘은 **크롬을 실행해서** `다운로드\로이창고\로이창고.html` 을 열고, 크롬이 없을 때만 기본 브라우저로 엽니다.
>
> 앱에 입력한 내용은 **여는 브라우저 안에** 저장됩니다. 크롬으로 열면 크롬에 저장되니, 늘 같은 브라우저(크롬)로 여는 것이 좋습니다.

> 폴더 이름(`다운로드\로이창고`)을 바꾸면 업데이터가 못 찾습니다. 그대로 두세요.
> 확장 프로그램을 예전에 다른 폴더에서 불러와 있었다면, `chrome://extensions` 에서 그 항목을 **[삭제]** 하고 위 폴더의 `로이창고_수집기` 로 새로 **[로드]** 해야 업데이트가 적용됩니다. (한 번만 하면 됩니다)

## 사용 흐름

1. 타오바오·티몰·1688·라쿠텐에서 상품을 보다가 **[🛒 로이창고로 수집]** 버튼 클릭 (버튼은 드래그해서 위치를 옮길 수 있고, 위치는 기억됩니다)
   1-b. 퍼센티는 **[신규 상품 등록]** 화면 왼쪽 아래 **[🛒 퍼센티 목록 수집]** → 현재 페이지 담기 / 선택만 / 범위·전체 자동 수집 (500건마다 분할 JSON 자동 저장, 일시정지·중단·이어서 지원, 상품마다 원문 타오바오·1688·라쿠텐 주소도 함께 조회)
2. 확장 프로그램 팝업에서 **[JSON으로 내보내기]**
3. `동작 > 로이창고.html` 에서 **[불러오기]** → **✨ 원클릭 번역·자동정리** 한 번이면 중국어·영어 상품명·옵션명과 **속성(소재·모델명·브랜드·카테고리·검색태그)**이 한국어로 번역되고, 금칙어·중복·50자·옵션 2~11개·배송비·판매가까지 정리됩니다.
4. 옷·신발이면 상세페이지에 **사이즈 공지**가 자동으로 들어갑니다. 상품명·카테고리·옵션명을 보고 앱이 알아서 고르며(윗옷 실측 / 바지 실측 / 신발 남녀 사이즈표), 상품 화면의 **[상세 공지 자동 삽입]** 에서 직접 고르거나 **[넣지 않음]** 으로 뺄 수 있습니다. 미리보기도 같은 자리에서 바로 보입니다. 상세 사진은 10장까지 상세페이지에 들어갑니다.
5. (선택) **상세이미지 10장 속 중국어·일본어 글자 번역** — **[⚙ 설정] → Gemini API 키**에 키를 넣으면, 사진 카드의 **[🖼️ 상세이미지 10장 글자 번역 (Gemini)]** 한 번으로 사진 속 상품설명·스펙·치수표·주의사항을 한국어로 읽어 **각 사진 바로 아래에 회색 안내 박스로** 상세페이지에 넣어 줍니다. 키를 여러 개 넣어 두면 한도(429)에 걸린 키는 건너뛰고 다음 키로 이어서 처리합니다.

## Gemini API 키 (v2.3)

- 키는 **[⚙ 설정] → Gemini API 키 (줄바꿈으로 여러 개 입력)** 에 넣습니다. 줄바꿈·쉼표로 여러 개를 넣을 수 있고, **이 브라우저의 localStorage에만 저장**됩니다. 저장소 파일·README·커밋에는 키가 들어가지 않습니다.
- 키가 있으면 상품명·옵션명도 Gemini가 더 자연스럽게 다듬고, 50자 이내·과장 문구 금지 규칙을 지킵니다. Gemini가 막히면 기존 구글 번역 → 내장 사전 순서로 자동 폴백합니다.
- 사진 속 글자 번역은 사진 주소에서 이미지를 받아야 하므로, 타오바오·1688 사진 서버가 직접 접근을 막아 두면 그 사진은 **건너뛰고 성공한 사진만** 넣습니다(실패 사진 수는 알림으로 알려 줍니다).
- **[키 상태 확인]** 버튼으로 넣은 키들이 실제로 동작하는지 한 번에 볼 수 있습니다.

## 탭별 기능 (v2.4)

### 🛒 상품 작업
기존 4단계(불러오기 → 번역·자동정리 → 사진 확인 → 마켓 내보내기) 그대로입니다.

- **퍼센티(KRW) 상품**은 `currency: KRW`로 읽어 원가를 **원화 그대로** 계산합니다(예전에는 위안으로 오해해 223배가 됐습니다). 통화 선택에 `원화(KRW)`가 생겼고, 원화 상품은 환율 칸 대신 `원화 그대로`로 표시됩니다.
- 상품 카드의 **[국내 위탁 (국내 택배비로 계산)]** 스위치를 켜면 해외 배대지 대신 **국내 택배비**로 배송비를 계산합니다.

### 📦 천조직구 신청서
받는 사람·상품·부가서비스를 넣고 **천조직구 [엑셀대량등록] 39칸 양식(.xlsx)** 으로 내려받습니다.

- 열 이름은 천조직구가 내려준 실제 양식(`downloads/대량등록_엑셀업로드_샘플_20260120-1.xlsx`)과 **한 글자도 다르지 않게** 맞췄습니다(줄바꿈 포함).
- 통관품목은 **주요 471건이 앱에 들어 있고**, 검색으로 고릅니다. 천조직구의 **[통관품목 다운로드] 파일(.xls)이나 CSV를 한 번 넣으면 4,698건 전체**에서 검색됩니다.
- 부가서비스 46종(코드·요금)을 체크박스로 고르면 AE열에 코드가 쉼표로 들어갑니다.
- **[⬇ 확장 자동입력용 JSON]** 을 내려받아 확장의 천조직구 신청서 화면에 넣으면 화면 칸이 자동으로 채워집니다.
- **접수·결제는 하지 않습니다.** 개인통관부호 유효체크와 [접수대기]/[접수신청]은 천조직구 화면에서 직접 누릅니다.

### 🏠 국내 위탁 (온채널 · 오너클랜 · 도매매)
- 원화 도매가 + 국내 택배비 + 마켓 수수료 + 목표 마진으로 **추천 판매가**를 계산합니다(환율·해외배대지 없음).
  `(도매가 + 국내택배) ÷ (1 − 수수료% − 목표마진%)`, 판매가는 설정의 올림 단위로 올립니다.
- 공급사 **CSV·엑셀(.xlsx/.xls)·JSON**을 그대로 불러오거나, 수집기 확장으로 상품 페이지에서 담아 옵니다. 엑셀은 압축을 직접 풀어 읽고(브라우저 기본 기능), 공급사 목록의 '12,300원' 같은 표기도 숫자로 바꿉니다.
- 줄마다 **[최저가]** 로 네이버 최저가 검색을 열고, **[상품으로]** 를 누르면 상품 작업으로 보내 스마트스토어 내보내기를 쓸 수 있습니다.
- **주의사항**을 화면에 함께 둡니다: 품절·도매가는 공급사가 수시로 바꿈, 최저가 경쟁, 배송비 조건, 이미지 사용 조건, 반품 주소, 원산지·KC 표시.

### 🧾 세무 장부
주문별 `판매금액 − 원가(해외원가 또는 국내도매가) − 배대지/국내배송비 − 마켓수수료 − 기타 = 순수익(과세표준)`을 정리해 **홈택스 소명·신고용 CSV/엑셀**로 내려받습니다.

- 주문 **CSV·엑셀**을 불러오거나, **[현재 상품으로 예상 장부]** 로 지금 상품의 판매가·원가·배송비·수수료를 한 줄씩 만들 수 있습니다.
- 엑셀은 **주문별 시트 + 월별 요약 시트** 두 장입니다.
- 부가세 참고값(매출×10/110 − 매입×10/110)은 **일반과세자·세금계산서 수취를 가정한 단순 계산**입니다. 구매대행은 직수입·위탁·영세율에 따라 달라지므로 **신고 전 세무사 확인**이 필요합니다.

## 개인정보

- 서버가 없는 단일 파일 앱입니다. 입력한 상품·설정은 사용하는 브라우저의 localStorage에만 저장됩니다.
- **이름 번역을 켜 두면 상품명·옵션명과 함께 속성(소재·모델명·브랜드·카테고리·검색태그)의 외국어가 구글 번역(translate.googleapis.com)으로 전송**됩니다. 사입가·사진·연락처·원본 상품 페이지 주소 같은 다른 정보는 전송되지 않습니다. 보내지 않으려면 앱 **[⚙ 설정] → 번역 방식 → 번역 없이 내장 사전 치환만**을 고르세요.
- 누끼(배경 제거) API 키를 직접 넣은 경우에만, 그 요청이 remove.bg 로 전송됩니다.
- **Gemini API 키를 넣은 경우에만** 상품명·옵션명과 상세이미지가 Google Gemini(generativelanguage.googleapis.com)로 전송됩니다. 사입가·연락처·설정값 같은 다른 정보는 전송되지 않습니다.
- **천조직구 신청서**에 넣은 받는 사람 이름·연락처·주소·개인통관고유부호는 이 브라우저(localStorage)에만 저장됩니다. 앱은 천조직구로 아무것도 보내지 않고, 파일로 내려받아 직접 올리거나 확장 프로그램으로 화면에 채울 뿐입니다.
- **천조직구 API 키** 칸은 이 브라우저에만 저장됩니다. 저장소·README·커밋에는 어떤 키도 들어가지 않습니다(기본값 빈 문자열).
- 백업·다른 PC로 이전은 앱의 **[JSON 내보내기]** / **[불러오기]** 를 사용하세요. ([번역·누끼 요청 파일]에도 Gemini 키는 들어가지 않습니다)
