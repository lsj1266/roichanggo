========================================================
 로이창고 상품 수집기 — 설치·사용 가이드
 (타오바오 · 티몰 · 1688 · 라쿠텐)
========================================================

한 번만 설치해 두면, 상품을 보다가 버튼 한 번으로
상품명·가격·옵션·썸네일·상세사진(최대 10장)까지 담아 두고
JSON 또는 CSV 파일로 내보내 「로이창고」에서 바로 쓸 수 있습니다.

· 상품 상세 페이지  → 오른쪽 아래 큰 버튼 [🛒 로이창고로 수집]
· 검색·목록 페이지  → 상품 카드마다 작은 버튼 [🛒 로이창고]

설치 시간은 약 1분입니다. 아래 순서대로만 따라 하세요.


--------------------------------------------------------
0. 준비 — 압축 풀기
--------------------------------------------------------
1) 받은 파일 "로이창고_수집기.zip"을 마우스 오른쪽 클릭
2) [압축 풀기] 선택  (윈도우 11은 [모두 압축 풀기])
3) "로이창고_수집기" 폴더가 생깁니다.

※ 이 폴더를 설치 후에 옮기거나 지우면 확장 프로그램이 꺼집니다.
   되도록 "문서" 폴더처럼 잘 안 지우는 곳에 두세요.
   (예: C:\Users\내이름\Documents\로이창고_수집기)

※ 한글 폴더 이름이 불편하면 영문으로 바꿔도 됩니다.
   (예: C:\Users\내이름\Documents\loi_changgo)


--------------------------------------------------------
1. 크롬 확장 프로그램 화면 열기
--------------------------------------------------------
1) 크롬을 열고 주소창에 아래를 입력한 뒤 Enter
      chrome://extensions
2) 확장 프로그램 관리 화면이 나옵니다.


--------------------------------------------------------
2. 개발자 모드 켜기
--------------------------------------------------------
1) 화면 오른쪽 위 [개발자 모드] 스위치를 클릭해 켭니다.
2) 스위치가 파란색이 되면 아래에 버튼 3개가 나타납니다.


--------------------------------------------------------
3. 압축해제된 확장 프로그램 불러오기
--------------------------------------------------------
1) [압축해제된 확장 프로그램을 로드합니다] 클릭
   (영문 크롬이면 [Load unpacked])
2) 폴더 선택 창에서 0번에서 압축을 푼
   "로이창고_수집기" 폴더를 선택하고 [폴더 선택] 클릭

   ※ 폴더 "안"의 파일(manifest.json)이 아니라
     "로이창고_수집기" 폴더 자체를 선택해야 합니다.

3) 목록에 "로이창고 상품 수집기" 카드가 생기면 설치 완료입니다.


--------------------------------------------------------
4. 아이콘 고정 (권장)
--------------------------------------------------------
1) 크롬 오른쪽 위 퍼즐 조각 모양 아이콘 클릭
2) 목록에서 "로이창고 상품 수집기" 옆 압정(📌) 클릭
3) 주황색 아이콘이 툴바에 고정됩니다.


--------------------------------------------------------
5. 사용법 ① — 상품 상세 페이지에서 담기
--------------------------------------------------------
1) 크롬에서 상품 상세 페이지를 엽니다.
   · 타오바오   item.taobao.com
   · 티몰       detail.tmall.com
   · 1688       detail.1688.com
   · 라쿠텐     item.rakuten.co.jp

2) 페이지 오른쪽 아래에 주황색 버튼이 뜹니다.
      [🛒 로이창고로 수집]

   ※ 버튼이 안 보이면 페이지를 한 번 새로고침(F5) 하세요.

3) 버튼을 클릭합니다.
   → "✅ 담았습니다 (3개) · 상세사진 8장" 처럼 표시됩니다.

   같은 상품 페이지에서 다시 누르면 중복으로 쌓이지 않고
   최신 가격·옵션·사진으로 갱신됩니다.


--------------------------------------------------------
6. 사용법 ② — 검색·목록 페이지에서 담기  ★새 기능
--------------------------------------------------------
1) 검색 결과나 카테고리 목록 페이지를 엽니다.
   · 타오바오 검색   s.taobao.com
   · 1688 검색       s.1688.com
   · 라쿠텐 검색     search.rakuten.co.jp

2) 상품 카드마다 오른쪽 위에 작은 버튼이 붙습니다.
      [🛒 로이창고]

3) 담고 싶은 상품의 버튼만 누르면, 그 상품의
   주소·상품명·가격·썸네일이 바로 저장됩니다.
   → 버튼이 [✅ 담음] 으로 바뀌고, 화면 아래에 개수가 표시됩니다.

   ※ 목록에서 담으면 상세사진·옵션은 비어 있습니다.
     필요하면 그 상품 페이지를 열어 [🛒 로이창고로 수집]을
     한 번 더 누르면 같은 상품에 사진·옵션이 채워집니다.
     (주소가 같으면 새 줄이 생기지 않고 갱신됩니다.)

   ※ 스크롤해서 더 불러온 상품에도 버튼이 자동으로 붙습니다.


--------------------------------------------------------
7. 담은 목록 보기 / 내보내기
--------------------------------------------------------
1) 툴바의 주황색 아이콘을 클릭하면 "로이창고 수집함" 창이 열립니다.
   · 상품명, 사이트, 가격, 옵션 일부, 사진 장수가 보입니다.
   · 제목을 클릭하면 원래 상품 페이지가 새 탭에서 열립니다.
   · 각 줄 오른쪽 [✕] 로 한 건만 삭제할 수 있습니다.

2) 아래 버튼으로 파일을 내보냅니다.
   [⬇ JSON 내보내기 (로이창고 불러오기용)]  ← 로이창고에 넣을 때
   [⬇ CSV 내보내기 (엑셀 확인용)]           ← 엑셀로 볼 때
   [🗑 전체 비우기]                          ← 목록 전체 삭제

3) 내보낸 파일은 크롬 "다운로드" 폴더에 저장됩니다.
   파일 이름 예: 로이창고_수집_20261120_1830.json


--------------------------------------------------------
8. 로이창고에 넣기
--------------------------------------------------------
1) 로이창고.html 을 크롬으로 엽니다.
2) 맨 위 [⬆ JSON/CSV 불러오기]를 누르고
   방금 내려받은 파일(JSON 또는 CSV)을 고릅니다.
3) 목록에 상품이 채워집니다.
   같은 주소·같은 상품명은 새로 쌓이지 않고 갱신됩니다.
4) [✨ 원클릭 자동정리] → [사진 확인] → [마켓 내보내기] 순서로 진행하세요.


--------------------------------------------------------
9. 내보낸 파일 형식
--------------------------------------------------------
[JSON] 상품 객체의 배열입니다.

[
  {
    "id": "p_1a2b3c_9x8y7z",
    "source": "1688",                  // taobao | 1688 | rakuten
    "sourceLabel": "1688",
    "url": "https://detail.1688.com/offer/123.html",
    "originalTitle": "원제 상품명",
    "price": 1280,                     // 숫자 (없으면 null)
    "currency": "CNY",                 // CNY | JPY
    "imageUrl": "https://cbu01.alicdn.com/...",   // 썸네일
    "images": ["https://...", "..."],             // 상세사진 최대 10장
    "options": ["블랙", "화이트"],               // 옵션(있으면)
    "from": "detail",                  // detail(상세) | list(목록)
    "collectedAt": "2026-11-20T09:30:00.000Z"
  }
]

[CSV] 엑셀에서 바로 열리는 형식 (UTF-8 BOM 포함, 한글 안 깨짐)
  칼럼: 수집일시 / 사이트 / 상품명 / 가격 / 통화 / 옵션 /
        이미지URL / 상세이미지 / 상품URL

※ 티몰(detail.tmall.com)은 타오바오 계열이라 source가 "taobao"로 저장됩니다.


--------------------------------------------------------
10. 자주 묻는 질문
--------------------------------------------------------
Q. 상세 페이지 버튼이 안 보여요.
A. ① 페이지를 F5로 새로고침 하세요.
   ② chrome://extensions 에서 확장 프로그램이 켜져 있는지 확인하세요.
   ③ 위 사이트의 상품 상세 페이지에서만 큰 버튼이 나옵니다.

Q. 목록 페이지에 작은 버튼이 안 붙어요.
A. ① 페이지를 새로고침(F5) 해 보세요.
   ② 그 사이트의 검색·목록 화면인지 확인하세요.
      (장바구니·마이페이지·주문서에는 붙지 않습니다.)
   ③ 사이트가 화면을 아주 늦게 그리는 경우, 스크롤을 조금 내리면 붙습니다.

Q. 가격이 "가격 미확인"으로 나와요.
A. 로그인 화면이나 오류 페이지에서는 가격을 읽을 수 없습니다.
   실제 상품 페이지에서 다시 눌러 주세요. 담기는 되지만 가격만 비어 있습니다.

Q. 옵션이 일부만 나와요.
A. 옵션(SKU) 영역 구조가 쇼핑몰마다 자주 바뀝니다.
   상품명·가격·사진은 정상으로 담기니, 옵션은 필요할 때 직접 확인하세요.

Q. 상세사진이 10장보다 적게 담겼어요.
A. 그 상품이 사진을 적게 쓰고 있거나, 상세 설명이 이미지가 아닌
   글·영상으로 되어 있을 때입니다. 사진은 로이창고에서 주소를 추가할 수 있습니다.

Q. 새로고침하면 목록이 사라지나요?
A. 아니요. 담은 목록은 크롬 안에 저장되어 브라우저를 껐다 켜도 남습니다.
   다만 확장을 삭제하거나 시크릿 모드에서 쓰면 저장되지 않습니다.

Q. 설치 후 "불러오지 못했습니다" 오류가 떠요.
A. 폴더를 잘못 선택한 경우입니다. manifest.json 파일이 아니라
   로이창고_수집기 폴더 자체를 선택했는지 확인하세요.

Q. 확장 프로그램을 업데이트(파일 교체)했어요.
A. chrome://extensions 에서 카드의 ↻(새로고침) 버튼을 누른 뒤,
   열려 있던 상품 페이지도 F5로 새로고침하세요.

Q. 다른 컴퓨터에서도 쓸 수 있나요?
A. 네. 같은 방법으로 설치하면 됩니다. 단, 담은 목록은 컴퓨터마다 따로
   저장되므로 옮기려면 JSON으로 내보낸 뒤 그 파일을 쓰면 됩니다.


--------------------------------------------------------
11. 안전 안내
--------------------------------------------------------
· 담은 데이터는 이 크롬 브라우저 안에만 저장되며 외부로 전송되지 않습니다.
· 로그인 정보나 결제 정보는 읽지 않습니다.
· 상품 페이지의 화면 내용(상품명·가격·사진 주소)만 읽어 오는 프로그램입니다.
